# Шпаргалка Neovim: клавиши и команды

Русский | [English](cheatsheet-neovim_en.md) | [PDF (русский и английский)](cheatsheet-neovim_ru-en.pdf)

Конфигурация для Windows 11: Python, Rust, PowerShell, Markdown, LaTeX, локальный ИИ-помощник · октябрь 2026

## Как читать

- `Esc` включает обычный режим (команды), `i` включает режим вставки (печать). Если не сказано иное, клавиши ниже нажимаются в обычном режиме.
- `Space a` означает: нажать пробел, отпустить, нажать `a`.
- Всё, что начинается с двоеточия, это команда: набрать её и нажать Enter.
- Слова вроде `word`, `old`, `new`, `file` в командах это подстановки: замените их своими.
- Пути в PowerShell можно писать с прямыми слэшами: `$env:LOCALAPPDATA/nvim` работает так же, как с обратными.

## Режимы

| Клавиши | Что делает |
|---|---|
| `i` | Режим вставки перед курсором |
| `o / O` | Новая строка ниже / выше и режим вставки |
| `Esc` | Выход в обычный режим |
| `jk` | В режиме вставки, нажатые быстро: то же, что Esc |
| `V` | Выделить строки целиком (затем j / k растягивают выделение) |
| `v` | Выделить по символам |

## Сохранение и выход

| Команда | Что делает |
|---|---|
| `:w` | Сохранить |
| `:wq` | Сохранить и выйти |
| `:q` | Выйти (не сработает, если есть несохранённые изменения) |
| `:q!` | Выйти без сохранения |
| `:qa` | Закрыть все окна |
| `:qa!` | Закрыть все окна без сохранения (выручает, когда открыты чат или дерево) |
| `:e!` | Выбросить несохранённые изменения и вернуть файл как при последнем сохранении |

## Перемещение

| Клавиши | Что делает |
|---|---|
| `j / k` | Вниз / вверх |
| `0` | В начало строки |
| `gg` | В начало файла |
| `G` | В конец файла |
| `:30 or 30G` | На строку 30 |
| `Ctrl+Home` | В начало файла |
| `Ctrl+w, w` | Переключиться между окнами (файл, дерево, чат) |

## Поиск и правка текста

| Клавиши | Что делает |
|---|---|
| `/word, Enter` | Найти слово в файле |
| `:44d` | Удалить строку 44 |
| `:25,$d` | Удалить строки с 25 до конца файла |
| `:%s/old/new/` | Заменить текст в файле (первое совпадение в каждой строке) |
| `cw` | Заменить слово под курсором: удаляет слово и включает вставку |
| `0, D` | Очистить строку целиком (D удаляет от курсора до конца строки) |
| `gg=G` | Выровнять отступы во всём файле |
| `u` | Отменить последнее действие (нажимать можно несколько раз) |
| `Ctrl+r` | Вернуть отменённое |

## Файлы и поиск

| Клавиши | Что делает |
|---|---|
| `:e $MYVIMRC` | Открыть init.lua |
| `:e $LOCALAPPDATA/nvim/lua/config/lazy.lua` | Открыть файл по пути |
| `Ctrl+p` | Поиск файла по имени (вместо стандартной клавиши) |
| `Ctrl+f` | Поиск текста по всем файлам проекта (вместо прокрутки страницы) |
| `Ctrl+n` | Открыть и закрыть файловое дерево слева |
| `Arrows, Enter, Esc` | В окнах поиска и в дереве: выбрать, открыть, закрыть |

Файлы конфигурации лежат в `$LOCALAPPDATA/nvim/`: `init.lua`, `lua/config/options.lua`, `lua/config/lazy.lua` (плагины), `lua/config/lsp.lua` (языковые серверы), `lazy-lock.json` (версии плагинов).

## Код: подсказки и автодополнение

| Клавиши | Что делает |
|---|---|
| `gd` | Перейти к определению функции или переменной (Python, Rust, PowerShell) |
| `Ctrl+y` | Принять выбранный вариант |
| `Ctrl+n / Ctrl+p / arrows` | Выбрать вариант в меню |
| `Ctrl+e` | Закрыть меню |
| `Ctrl+Space` | Вызвать меню вручную |

Ошибки и предупреждения от языкового сервера показываются текстом справа от строки. Запись `E:2 W:1` в строке статуса показывает количество ошибок и предупреждений в файле. Меню автодополнения появляется само при наборе.

Примечание: в стандартной раскладке плагина blink.cmp клавиша Enter вариант не принимает, для этого нужен `Ctrl+y`.

Сервер запускается через 10–30 секунд после открытия файла. Если подсказок нет, выполните `:checkhealth vim.lsp`.

## Markdown

| Команда | Что делает |
|---|---|
| `:RenderMarkdown toggle` | Включить или выключить оформленный вид Markdown |
| `:set ft?` | Какой тип файла определил Neovim (для Markdown должно быть filetype=markdown) |

Оформление показывается в обычном режиме, а в режиме вставки виден исходный текст разметки. Языковой сервер для Markdown называется marksman; подключён ли он, показывает `:checkhealth vim.lsp`.

## LaTeX (VimTeX)

| Клавиши | Что делает |
|---|---|
| `\ll` | Запустить непрерывную сборку PDF |
| `\lv` | Открыть PDF |
| `\le` | Показать ошибки сборки |
| `\lk` | Остановить сборку |
| `\li` | Информация VimTeX (проект, компилятор) |
| `\lc` | Удалить служебные файлы сборки (.aux, .log и др.) |
| `:VimtexInfo` | То же, что `\li`, командой |
| `:Mason` | Окно менеджера языковых серверов |
| `:MasonInstall texlab marksman` | Установить серверы для LaTeX и Markdown |

Знак `\` это клавиша Backslash. Для сборки нужны MiKTeX и Perl; подробности в инструкции [`install-markdown-latex`](install-markdown-latex_ru.md).

## ИИ-помощник (локальная модель)

Перед работой Ollama должна быть запущена (значок ламы в трее). Модель: `qwen2.5-coder:7b`, контекст 16384 токена.

| Клавиши | Что делает |
|---|---|
| `Space a` | Открыть и закрыть чат |
| `V, j/k, Space c` | Отправить выделенный код в чат |
| `V, j/k, Space i` | Правка выделенного кода по вашей задаче |
| `i, Ctrl+s` | В чате: начать печатать и отправить вопрос |
| `g2 / g3 / g1` | Принять / отклонить / всегда принимать правку |
| `ga` | В чате: выбрать другую модель |

Команды: `:CodeCompanionChat` (открыть чат), `:CodeCompanionChat Toggle`, `:CodeCompanionChat Add` (добавить выделение), `:CodeCompanion task text` (правка на месте; вместо `task text` напишите задачу).

Клавиши `g1`, `g2`, `g3` и `ga` назначены самим плагином codecompanion.nvim; в других версиях плагина они могут быть другими.

**Вопрос по коду.** Выделить код (`V`, `j`/`k`), `Space c`, `i`, вопрос, `Ctrl+s`. Ответ приходит через 10–20 секунд.

**Правка кода.** Выделить код, `Space i`, написать задачу, Enter. Правка появится отдельным блоком: `g2` принять, `g3` отклонить. Результат всегда стоит просмотреть: 7B-модель иногда ошибается в деталях (например, ставит комментарий не туда).

Совет: выделяйте нужную функцию, а не весь файл. Так ответы точнее, а контекст не переполняется. Проверка работы на видеокарте: `ollama ps` (должно быть `100% GPU`).

## Диагностика и служебные команды

| Команда | Что делает |
|---|---|
| `:checkhealth` | Общая проверка состояния |
| `:checkhealth vim.lsp` | Работают ли языковые серверы |
| `:checkhealth lazy` | Состояние менеджера плагинов |
| `:checkhealth nvim-treesitter` | Установленные парсеры подсветки |
| `:checkhealth vim.provider` | Проверка провайдеров (Python, Node и др.) |
| `:Inspect` | Чем подсвечено слово под курсором (подтверждает работу Treesitter) |
| `:set ft?` | Какой тип файла определил Neovim |
| `:TSInstall python` | Установить парсер подсветки для языка (также rust, lua) |
| `:Lazy` | Окно менеджера плагинов; q закрывает его |

## Частые проблемы

- **E37: No write since last change.** Файл не сохранён. Нажмите `:wq` или `:q!`.
- **E486: Pattern not found.** Искомого текста нет в текущем файле или окне. Часто поиск запускают не в том файле.
- **Чат или команды «ломаются».** Мешает Punto Switcher. Настройки, затем «Программы-исключения», добавить `WindowsTerminal.exe`.
- **Чат не даёт печатать.** Он открывается в обычном режиме. Нажмите `i`.
- **`:q` не закрывает окно при открытых чате или дереве.** Используйте `:qa!`.
- **Parser could not be created for language.** Не установлен парсер. Выполните `:TSInstall language`, подставив название языка.
- **Подсказок кода нет.** Подождите 10–30 секунд и выполните `:checkhealth vim.lsp`.
- **Ответ модели не приходит.** Проверьте, что Ollama запущена (значок в трее, `ollama ps`).
- **Сборка LaTeX не запускается: «could not find the script engine perl».** Не установлен Perl. См. инструкцию [`install-markdown-latex`](install-markdown-latex_ru.md).
